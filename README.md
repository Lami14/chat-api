# Chat API

A real-time chat backend built with **Node.js, Express, Socket.io, and MongoDB**.  
This project demonstrates **backend development, authentication, real-time communication, and database integration**.

---

## Features

- **User authentication** with JWT
- **Real-time chat rooms** using Socket.io
- **Persistent messages** stored in MongoDB
- **Protected routes** for fetching chat history
- **Scalable structure** for adding more features like multiple rooms, private messages, or media
